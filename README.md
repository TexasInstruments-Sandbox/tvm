# TVM for TI C7™ NPU

This is a fork of [Apache TVM](https://github.com/apache/tvm) that adds
a compiler backend and runtime for Texas Instruments' C7™ NPU, paired
with Arm cores in TI's AM67A/J722S SoCs.

> **Not production-ready.** This is an active work-in-progress fork.

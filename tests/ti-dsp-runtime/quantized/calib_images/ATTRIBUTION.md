# Image attribution

Real-image calibration set for the quantized model tests in this directory.
Kept separate from tests/cstatic/test_images/ because other tests load every
*.jpg in that directory; adding files there would change their inputs.

Each image is a Wikimedia Commons "Quality image" released as CC0 or public
domain, so none requires attribution; all are credited here for provenance.
Files were downscaled to a 384 px short side (enough for inception_v3's
342 px resize), converted to sRGB and saved as JPEG quality 85 without
metadata.

# C7x Arm Runtime

Arm-side shared library (`libc7x_arm_runtime.so`) backing the C++
`c7x::Module` / Python `C7xVirtualMachine` inference API: build/deploy
scripts and the IPC client implementation.

See [Deploying Firmware](../../../../../../docs-c7x/user-guide/deploying-firmware.md)
in the docs site for build/deploy instructions, and
[ARM Host Client Internals](../../../../../../docs-c7x/contributor-guide/firmware/arm-client-internals.md)
for the internal design.

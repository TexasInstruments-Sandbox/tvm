# TI DSP Runtime Tests

Tests for the TVM TI DSP runtime, covering DSP model execution and TIDL
subgraph offloading on C66x (AWRL6844) and C7x (J722S/AM67A) targets.

See [Testing Overview](../../docs-c7x/contributor-guide/testing/overview.md)
in the docs site for the DSP test suite reference (TIDL tests are not
covered there; see `tidl-tests/README.md` in this directory).

# TVM DSP Integration

Infrastructure for running TVM-compiled models on TI DSP hardware (C66x
and C7x) using the minimal DSP runtime, including the standalone JTAG
test harness and its J722S memory/MMU configuration.

See [DSP C++ Harness](../../../docs-c7x/contributor-guide/testing/dsp-cpp-harness.md)
in the docs site for build/usage instructions, and
[C7x Memory Map Reference](../../../docs-c7x/contributor-guide/dsp-runtime/memory-map.md)
for the memory layout and MMU configuration.

# TVM DSP Runtime

Minimal runtime for executing TVM-compiled models on TI DSP processors:
a lightweight C++14 API (`model.h`) with static memory pools and
zero-copy design.

See [Embedding the DSP Runtime (C++ API)](../../../docs-c7x/user-guide/embedding-cpp-api.md)
in the docs site for the public API reference, and
[DSP Runtime Internals](../../../docs-c7x/contributor-guide/dsp-runtime/internals.md)
for build instructions and internal memory architecture.
